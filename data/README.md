# 数据字典

合成记录采用 UTF-8 JSON 数组。主键和字段名称见 `manifest.json`。空值为来源未提供。

occurred 为业务发生日期，available 为记录到中心日期，均含当天。正式更改目标从发生日起终止旧目标的后续观察，不能用新目标的验收补旧目标。基线工艺与开题年份由 projects 给出。一个项目阶段配合抽核占一小时，跨站同一原始记录只可成为一次独立证据。

- `projects.json`　提交时声明的目标、工艺和合同服务类型。
- `packages.json`　必要子包及可选子包，按主合同归属。
- `events.json`　受理后事件及资料出现日期；转接后使用原项目号，复验追溯原记录。
- `services.json`　本地或外地服务实用阶段及合同。
- `review_policy.json`　观测截面、跟踪期限、可比组下限和有业务意义的差异下限。
- `windows.json`　参加下一轮抽核的时段和能提供的记录。
- `renewal.json`　已续购决定、核定数与原观察截面。
